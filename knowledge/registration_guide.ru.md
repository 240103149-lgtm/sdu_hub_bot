# **Общие сведения**

Регистрация на курсы проходит каждый семестр на портале [my.sdu.edu.kz](https://my.sdu.edu.kz/) в разделе Academic Operations → Course Registration. За курс, по которому в портале нет записи о регистрации, кредиты не начисляются.

Официальное руководство в портале (Portal Guideline) — [Student Handbook](https://my.sdu.edu.kz/common/download/handbook.pdf) 2021 года (46 страниц). В нём лишь несколько общих правил регистрации и нет пошаговой инструкции. Поэтому это руководство составлено по самим страницам портала.

# **Перед регистрацией**

Окно регистрации открывается раз в семестр и работает всего 9–12 дней. Выберите курсы заранее.

* Откройте Information → System Calendar, выберите семестр и посмотрите даты в строке «Course Registration (for students)». В таблице Individual Permissions ниже указано ваше личное окно регистрации — оно может открыться позже общего периода регистрации.
* Учебный план по семестрам находится в Academic Operations → My Curriculum. Элективы отмечены кодом «XXX», а доступные коды курсов указаны в скобках. «Available» в столбце Status означает, что курс можно взять, а «IP» в поле оценки — что курс сейчас идёт.
* Заранее обсудите выбранные курсы с эдвайзером. Имя вашего эдвайзера указано на главной странице портала.
* Проверьте баланс в Information → MY Accounting Info. На странице Course Registration показана стоимость каждого курса.

Этапы регистрации на осенний семестр 2026 года

Регистрация закрывается до начала занятий; после этого остаются только периоды корректировки. 2026–2027 учебный год, осенний семестр, по данным System Calendar.

| Этап | Даты в 2026 году |
| :---- | :---- |
| Course Registration (регистрация на курсы) | 10–21 августа |
| Начало занятий | 1 сентября |
| Add - Drop | 7–13 сентября |
| Поздняя регистрация (платная) | 14–19 сентября |
| Early withdrawal (ранний отказ от курса) | 21 сентября – 17 октября |
| Late withdrawal (поздний отказ от курса) | 19 октября – 12 декабря |

Некоторые периоды закрываются в 00:00 указанного последнего дня. Например, Early withdrawal заканчивается 17 октября в 00:00, то есть последний день для отказа — 16 октября. Весенний семестр проходит в том же порядке: в 2026 году регистрация шла 8–16 января, а Add-Drop — с 26 января по 1 февраля.

# **Wish list для планирования заранее**

Wish list — это список для планирования следующего семестра; он не регистрирует вас на курсы. Зарегистрироваться всё равно нужно через Course Registration в даты, указанные в календаре.

1. Откройте Academic Operations → Wish list.
2. В разделе Wish List basket выберите семестр, например 2026 - 2027 Spring.
3. В таблице Course structure ниже нажмите add рядом с курсом. Для группы элективов нажмите Choose и выберите конкретный курс из этой группы.
4. Над корзиной показаны сумма ECTS и лимит: 40 ECTS на осенний и весенний семестры и 20 ECTS на летний.
5. Чтобы убрать ненужный курс, нажмите remove в столбце OPERATION.

# **Регистрация на курсы пошагово**

Когда ваше окно откроется, перейдите в Academic Operations → Course Registration. Если окно закрыто, на странице будет надпись «Course registration is CLOSED».

1. Проверьте программу. Обычно там указано «M - Main Track». Только если у вас есть вторая программа, отметьте «Check to switch program» и переключитесь через список.
2. Найдите курс. Выберите тип поиска и нажмите Show или введите код курса в поле поиска. Элективы отображаются в своих группах.
3. Выберите секции. Сначала выберите секцию N (Normal) — это лекционная секция. После этого появятся связанные с ней секции P (практика) и L (лаборатория); выберите по одной из каждой.
4. Проверьте расписание. Выбранные секции сразу появляются в сетке Course schedule ниже. Значения цветов — в таблице ниже.
5. Добавьте курс. Нажмите add и подтвердите «Are you sure about adding selected section?». Для электива сначала укажите группу электива.
6. При необходимости удалите курс. Когда вы удаляете курс из списка, портал спрашивает «Cancel selected section?».
7. Подтвердите регистрацию. Добавив все курсы, нажмите кнопку подтверждения и подтвердите «Do you want your selected courses to be approved?». Статус сменится на STUDENT CONFIRMED; утверждённая регистрация отображается на странице как APPROVED.
8. Проверьте итоговый список. В таблице указаны код курса, секции N/P/L, cr (кредиты), ECTS, статус («First time» — вы берёте курс впервые) и стоимость. В последней строке — сумма ECTS.

| Цвет в расписании | Метка | Значение |
| :---- | :---- | :---- |
| Светло-зелёный | In basket | Курс добавлен в ваш список |
| Светло-голубой | Available | Секцию можно выбрать |
| Синий | Selected | Секция, которую вы сейчас выбираете |
| Розовый | Unavailable | Пересекается с другим курсом; добавить нельзя |

# **Запросы на разрешение (Consent Requests)**

Для регистрации на некоторые секции нужно разрешение, например если вы ещё не прошли пререквизит. Курсы с пререквизитами отмечены PR в столбце requisites на странице My Curriculum.

1. На странице Course Registration выберите секцию N курса. Если нужно разрешение, откроется форма сообщения.
2. Кратко объясните, почему хотите взять этот курс. С пустым полем запрос не отправится.
3. Подтвердите «Do you really want to send a request?». «Sent successfully!» означает, что запрос отправлен.
4. Следите за ответом в Academic Operations → Consent Requests.

Возможные ответы портала:

* «You have already sent request» — запрос уже отправлен; дождитесь ответа.
* «You were refused» — запрос отклонён; выберите другую секцию или курс.
* «Consent Request NOT AVAILABLE for this section» — для этой секции запросить разрешение нельзя.

# **После регистрации**

После закрытия регистрации есть три периода, когда можно изменить список курсов. Их даты указаны в таблице этапов регистрации выше.

* Add - Drop — первая неделя занятий. Можно добавлять и удалять курсы, а также менять секции.
* Apply for Late Course Registration — для тех, кто не зарегистрировался вовремя. Портал предупреждает, что заявка платная, оплата не возвращается, а отозвать заявку нельзя.
* Early / Late withdrawal — отказ от курса через Academic Operations → Withdrawals. Прежде чем принять решение, поговорите с эдвайзером.

Итоговое расписание находится в Academic Operations → Course Schedule и внизу страницы Course Registration. Посещаемость можно отслеживать в Electronic Attendance.

# **Правила и лимиты**

За семестр можно взять 20–40 ECTS; рекомендуется 30 ECTS. Лимит считается по ECTS, а не по столбцу cr (кредиты).

| Правило | Значение | Источник |
| :---- | :---- | :---- |
| Нагрузка за семестр | 20–40 ECTS; рекомендуется 30 | [Student Handbook](https://my.sdu.edu.kz/common/download/handbook.pdf), 2021 |
| Лимит планирования | Осень и весна: 40 ECTS; лето: 20 ECTS | Страница Wish list |
| Курс без регистрации | Кредиты не начисляются | [Student Handbook](https://my.sdu.edu.kz/common/download/handbook.pdf), 2021 |
| Посещаемость | При пропуске 30% часов курса курс не засчитывается | [Student Handbook](https://my.sdu.edu.kz/common/download/handbook.pdf), 2021 |
| Поздняя регистрация | Платная; оплата не возвращается | Страница Course Registration |
| Пререквизит | Отмечен PR на странице My Curriculum | Страница My Curriculum |

Условия Add-Drop, отказа от курса и поздней регистрации описаны в положении об учебном процессе по кредитной системе (Regulation on the credit system-based teaching process) на странице Rules and Regulations: [на казахском](https://files.sdu.edu.kz/pms/rule-attachments/0KPN5EtRQ6ZpyRdjVA5ahcBdd8OgpVOE8jOJHbC1.pdf), [на английском](https://files.sdu.edu.kz/pms/rule-attachments/WNJyGU00oPPYhpCC6XfJJRSZQfwpl5z4WUjQyBrr.pdf).

# **Частые сообщения портала**

Портал показывает ошибки короткими всплывающими сообщениями на английском. Самые частые из них:

| Сообщение | Значение | Что делать |
| :---- | :---- | :---- |
| Unavailable sections selected! | Секция пересекается с другим курсом в вашем расписании | Выберите другую секцию |
| Normal section of course is not identified! | Не выбрана секция N | Сначала выберите секцию N |
| Practice section of subject is not identified. | Не выбрана секция P | Выберите практическую секцию |
| LAB section of subject is not identified. | Не выбрана секция L | Выберите лабораторную секцию |
| Group of elective course is not identified! | Не определена группа элективов | Укажите, какой элективный слот займёт курс |
| Search criteria is empty. | Поле поиска пустое | Введите код курса |
| Please fill message field | В запросе на разрешение не указана причина | Заполните поле сообщения |

По вопросам выбора курсов, разрешений и отказа от курса сначала обращайтесь к эдвайзеру. Административные вопросы решает Student Service Centre (центр обслуживания студентов). Если не получается войти, нажмите «Can't access my account» на странице входа.
